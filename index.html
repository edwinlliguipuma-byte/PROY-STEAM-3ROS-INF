🎯 ¿Qué es el Proyecto STEAM?

S Ciencia   T Tecnología   E Ingeniería   A Arte   M Matemáticas

El proyecto "Cáncer y Autómatas Celulares" conecta las matemáticas con la biología celular, específicamente con el estudio de la proliferación de células cancerosas.

🔬 Contexto Científico

Las células cancerosas se caracterizan por su capacidad de dividirse de manera descontrolada. En condiciones normales, las células se dividen siguiendo patrones regulares que pueden modelarse matemáticamente mediante sucesiones.

🧫 Simulación visual de proliferación celular
💡 Dato importante: En este proyecto modelaremos cómo crece una población de células cancerosas usando sucesiones matemáticas. Cada célula se divide en 2 (o se triplica) en cada etapa.

📐 ¿Qué es una Sucesión?

Una sucesión es un conjunto ordenado de números que siguen un patrón o regla determinada. Cada número de la sucesión se llama término.

📝 Notación

Los términos de una sucesión se denotan como:

a₁, a₂, a, a₄, ..., aₙ, ...

Donde aₙ representa el término en la posición n.

Ejemplo

Considera la sucesión: 2, 4, 6, 8, 10, ...

  • a₁ = 2 (primer término)
  • a₂ = 4 (segundo término)
  • a₃ = 6 (tercer término)
  • aₙ = 2n (término general)

🎯 Tipos de Sucesiones

Existen dos tipos principales que estudiaremos:

  • Sucesiones Aritméticas: La diferencia entre términos consecutivos es constante
  • Sucesiones Geométricas: El cociente entre términos consecutivos es constante

➕ Sucesiones Aritméticas

En una sucesión aritmética, la diferencia entre dos términos consecutivos es siempre la misma. Esta diferencia se llama razón aritmética (d).

Fórmula del Término General

aₙ = a₁ + (n - 1) · d

Donde:

  • a₁ = primer término
  • d = diferencia constante
  • n = posición del término

Ejemplo Resuelto

Ejemplo: Sucesión 3, 7, 11, 15, 19, ...
Paso 1: Identificar a₁ = 3
Paso 2: Calcular d = 7 - 3 = 4
Paso 3: Aplicar fórmula: aₙ = 3 + (n-1)·4 = 4n - 1
Paso 4: Calcular a₁₀ = 4(10) - 1 = 39

✅ Características

  • La diferencia d puede ser positiva (sucesión creciente) o negativa (decreciente)
  • El crecimiento es lineal
  • Gráficamente forma una línea recta

✖️ Sucesiones Geométricas

En una sucesión geométrica, el cociente entre dos términos consecutivos es siempre el mismo. Este cociente se llama razón geométrica (r).

📐 Fórmula del Término General

aₙ = a₁ · r^(n-1)

Donde:

  • a₁ = primer término
  • r = razón constante (cociente)
  • n = posición del término

🔍 Ejemplo Resuelto

Ejemplo: Sucesión 2, 6, 18, 54, 162, ...
Paso 1: Identificar a₁ = 2
Paso 2: Calcular r = 6/2 = 3
Paso 3: Aplicar fórmula: aₙ = 2 · 3^(n-1)
Paso 4: Calcular a₅ = 2 · 3⁴ = 2 · 81 = 162 ✓

✅ Características

  • La razón r puede ser mayor que 1 (crecimiento exponencial) o entre 0 y 1 (decrecimiento)
  • El crecimiento es exponencial (muy rápido)
  • Es el modelo que usaremos para la proliferación celular
📈 Crecimiento geométrico vs aritmético

🧬 Proyecto STEAM: Cáncer y Autómatas Celulares

Aplicaremos las sucesiones geométricas para modelar el crecimiento de células cancerosas.

🔬 Modelo Matemático

Si una población de células cancerosas se duplica en cada etapa:

aₙ = a₁ · 2^(n-1)

Si se triplica en cada etapa:

aₙ = a₁ · 3^(n-1)

🎯 Relación de Recurrencia

La relación de recurrencia describe cómo obtener el siguiente término a partir del anterior:

aₙ₊₁ = 2 · aₙ    (si se duplica)
aₙ₊₁ = 3 · aₙ    (si se triplica)
💡 Aplicación real: Los médicos usan estos modelos para predecir el crecimiento de tumores y planificar tratamientos. Conocer la fórmula explícita permite calcular cuántas células habrá en cualquier etapa sin tener que calcular todas las anteriores.

📝 Ejemplos Completos

Ejemplo 1: Células que se duplican

Problema: Un tumor comienza con 5 células cancerosas y se duplica en cada etapa. ¿Cuántas células habrá en la etapa 6?

Solución:
• a₁ = 5, r = 2
• Fórmula: aₙ = 5 · 2^(n-1)
• a₆ = 5 · 2⁵ = 5 · 32 = 160 células

Ejemplo 2: Células que se triplican

Problema: Una población de 2 células se triplica en cada etapa. Hallar a₄ y la fórmula explícita.

Solución:
• a₁ = 2, r = 3
• Fórmula: aₙ = 2 · 3^(n-1)
• a₄ = 2 · 3³ = 2 · 27 = 54 células

Ejemplo 3: Identificar el tipo de sucesión

Problema: La sucesión 4, 12, 36, 108, ... ¿es aritmética o geométrica?

Solución:
• Diferencias: 12-4=8, 36-12=24 (no constante) → NO es aritmética
• Cocientes: 12/4=3, 36/12=3, 108/36=3 (constante) → Es geométrica con r=3
• Fórmula: aₙ = 4 · 3^(n-1)
